# FieldDesk API

NestJS 11 with Express. Run `pnpm dev:api` from the repository root, or
`pnpm --filter @fielddesk/api start` after `pnpm build`.

`GET /` returns `Hello World!`. The default port is 3001; `PORT` overrides it.
`pnpm test` runs the generated controller unit test and HTTP smoke test.

See the [root README](../../README.md) for setup and workspace standards.

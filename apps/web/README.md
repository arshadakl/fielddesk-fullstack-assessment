# FieldDesk web

Next.js 16 App Router, TypeScript, and Tailwind CSS. Run `pnpm dev:web` from the
repository root, or `pnpm --filter @fielddesk/web start` after `pnpm build`.

The starter page runs on port 3000 and uses system fonts. Application features
and API integration are deferred.

See the [root README](../../README.md) for setup and workspace standards.
